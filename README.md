# مذاق | Restaurant Landing Pages

صفحة تسويقية عربية لبيع تصميم صفحات المطاعم والمقاهي في البحرين.

## التشغيل
افتح `index.html` في المتصفح. لا يحتاج المشروع إلى خادم أو أدوات بناء.

## المميزات
- تصميم عربي RTL متجاوب.
- أقسام تعريفية ومميزات وخطوات العمل.
- دعوة للتواصل عبر واتساب: +973 66346899.
- HTML/CSS/JavaScript بدون إطار عمل.

## النشر عبر GitHub Pages
من إعدادات المستودع: Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

> ملاحظة: المستودع حاليًا خاص. تحقق من أهلية GitHub Pages وخيارات إتاحة الموقع ضمن خطتك قبل النشر. النشر لم يتم تلقائيًا.

## ملاحظات قبل الإطلاق التجاري
- اسم «مذاق» اسم مبدئي قابل للتغيير.
- صور Unsplash الخارجية تحتاج اتصالًا بالإنترنت؛ يُفضّل استبدالها بصور مرخصة ومملوكة للمشروع.
- نموذج «مطعم الذوق» توضيحي وليس عميلًا حقيقيًا.
- أضف شعار المشروع والأسعار والباقات وشهادات العملاء بعد توفرها.
